Math Dreamweaver · Calculus Lab

See how a derivative is solved, one rule at a time. CortexJS records real intermediate steps; Nerdamer computes a second symbolic answer, and MathJax renders both as textbook mathematics. Everything works offline.

Tutor Mode starts at Step 0 so you can choose the first rule. Calculator Mode gives the immediate CAS result. Neither mode silently invents unsupported transformations.

Try (x^2+3)^4, sin(x)/x, or (x+1)^3.

How this helps you learn

Tutor Mode: begin with Step 0, predict the first rule, type your own next expression, request three progressively stronger hints, then reveal the recorded transformation. Calculator Mode: see the symbolic answer immediately. Student-entered lines are checked conservatively: symbolic equality and finite counterexamples are useful, but neither samples nor CAS simplifications establish a complete domain-aware proof. Integration, limits and other operations do not yet have guided traces. The original derivative tutor remains available.

Inspired by EquationWright's bundled MathJax 3.2.2 (TeX → SVG) approach. No CDN, analytics, or internet connection is used by this finished offline package. Input supports a deliberately limited LaTeX subset.
